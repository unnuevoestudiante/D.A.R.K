# Condiciones de la prueba privada de D.A.R.K.

**Canal:** Tester privado · **Versión:** tester-v1

Esta copia de D.A.R.K. se entrega a una persona invitada únicamente para evaluación previa al lanzamiento. No es una oferta de venta, no inicia una suscripción comercial y no concede derechos de redistribución.

El acceso al instalador usa un código compartido por la persona responsable de la prueba. El código protege la entrada casual al instalador; no es una licencia comercial ni una medida contra modificaciones del programa. Una vez instalado, esta copia no tiene fecha de vencimiento.

La versión puede cambiar, fallar o perder datos. Úsala solo en el equipo de prueba y evita ingresar información sensible. La persona tester puede informar problemas a quien le compartió esta copia. No se promete soporte ni continuidad del servicio.

D.A.R.K. incluye componentes de terceros. Sus avisos y licencias aparecen por separado y siguen rigiendo para cada componente. Si configuras una API externa, su proveedor puede recibir los datos que envíe D.A.R.K. y aplicar sus propios términos, tarifas y políticas. Usa únicamente claves que te pertenezcan o que tengas autorización para usar.

La desinstalación de esta prueba quita la aplicación y conserva la configuración, tareas, modelos y logs del usuario, salvo que la persona decida eliminarlos por separado.

Al continuar con la instalación, confirmas que entiendes que se trata de una copia privada de prueba y que la usarás para evaluar D.A.R.K., no para revenderla o redistribuirla.
