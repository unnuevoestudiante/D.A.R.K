# Instalación y primer arranque

Los documentos de esta carpeta describen el trabajo de instalación por etapa. Para el estado actual, da prioridad a:

- `M1_CONFIGURACION_CENTRAL.md`: configuración compartida y precedencia.
- `M5_1_CATALOGO_ARTEFACTOS.md` y `M5_2_PAQUETE_REPRODUCIBLE.md`: catálogo y ensamblado del payload.
- `M5_3_CONDICIONES_Y_FIRMA.md`: metadatos, firma y bloqueos de publicación.
- `PENDIENTES_INSTALADOR_Y_PRIMER_ARRANQUE.md`: decisiones y validaciones todavía abiertas.
- `TRASPASO_RUTA_INSTALADOR_Y_PRIMER_ARRANQUE.md`: secuencia del proyecto y estado de fases.

`M0_1/` conserva el diseño de referencia inicial. Sus descripciones de componentes, arranque y distribución son históricas y anteriores al código de `DarkSetup`, `DarkInstaller` y `DarkSupervisor`; no describen la implementación actual.
